경마 Plus - 무료 경마 예상·출마표·배당·AI 분석 앱

경마 Plus는 한국마사회 공공데이터를 기반으로 한 무료 경마 정보 앱입니다. 서울경마(렛츠런파크 서울 / 과천경마장), 부산경마(렛츠런파크 부산경남 / 부산경마장), 제주경마(렛츠런파크 제주 / 제주경마장)의 오늘 경마 출마표와 실시간 배당, 경주 결과, 경주마·기수·조교사 기록까지 모바일에서 한 번에 확인할 수 있습니다.

주요 기능

  • 경마 출마표 / 출전표 조회 — 오늘 경마, 주말 경마 일정 안내
  • 실시간 경마 배당 — 단승·복승·삼복승 배당률 변동 추적
  • 경주 결과 조회 — 오늘 경마 결과, 과거 경주 기록
  • 경주마 정보 / 경주마 기록 — 출전 이력, 성적, 혈통
  • 기수 정보 / 조교사 정보 — 승률, 입상률, 최근 폼
  • AI 경마 예상 / AI 우승 예측 — 데이터 기반 경마 예측
  • 경마 통계 / 데이터 분석 — 경마 순위 분석, 기록 조회
